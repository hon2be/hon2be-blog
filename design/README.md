## 핵심 원칙

1. **픽셀 퍼펙트** — 모든 요소는 날카로운 모서리(border-radius: 0), 명확한 그림자 오프셋을 사용한다.
2. **모노스페이스 우선** — 전체 타이포그래피는 Mona 모노스페이스 폰트 단일 체계를 따른다.
3. **분홍 단색 팔레트** — `--accent: #f07098` (스프라이트 꽃잎 중간 분홍)을 중심으로 한 단일 색조 팔레트.
4. **3D 프레스 효과** — 인터랙티브 요소는 box-shadow + translate로 물리적 클릭감을 표현한다.
5. **벚꽃 모티프** — 배경 폴카닷 패턴, 낙하 꽃잎, 그라디언트 구분선으로 테마를 유지한다.
